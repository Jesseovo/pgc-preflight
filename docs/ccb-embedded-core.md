# CCB Worker 内嵌查询内核

内核移植自 CCB 固定提交 `963e0013184ecc1521289a0fc7d5da4bb6e45356` 的非流式工具执行路径。模型流仍由宿主协议层解析，内核收到完整且可核验的模型响应后调度工具。源码文件、片段位置和 SHA-256 见 [移植来源清单](./ccb-embedded-core-provenance.json)。上游原始片段在干净 checkout 的测试中可直接运行，本地还会核对完整固定源码。

| 行为 | 内嵌范围 |
| --- | --- |
| 查询状态与终止 | 保留工具块驱动的继续条件、完成后的消息追加和轮次推进。干净的无工具终止可没有最后一段文字。制作和审核的交付物由外层按原规则校验。 |
| 消息与工具 | 助手原生思考和签名在当前轨迹内原样传递。工具结果紧随对应助手轮次，缺失、孤立或重复 ID 拒绝。相邻只读工具并发，结果按完成顺序合流。修改工具独占执行。 |
| 错误与预算 | 可预期的工具错误可由模型在剩余额度内处理。工作区异常、响应中断或截断会停止查询。初始调用、后续调用和压缩共用额度，未知输出用量保留请求上限。 |
| 上下文压缩 | 沿用有效窗口和压力阈值，仅压缩完整的较早工作轮次。同一模型生成摘要，最新工作轮次、原始任务材料及截图仍可用。压缩采用独立的工作摘要提示，默认上下文用量为估算。 |

移植范围排除 CLI 附件和通知、交互权限钩子、流中工具执行、后台会话、缓存和会话记忆压缩、自动补写及模型回退。原有模型、工作区授权、持久恢复和正式交付校验由宿主管理。阶段结果只导出最终文本和用量，原生思考及签名仅在运行期间持有。

当前证据限于固定源码对照和本地合成测试。真实模型制作、审核质量及正式发布仍待验证。
