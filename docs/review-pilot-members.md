# 灰测成员与 Creator 账号设置

管理员在 `/admin?view=members` 打开某位成员的「管理」，使用独立的「灰测与 Creator 账号」设置。该设置记录灰测参与和管理员确认的账号对应关系，不改变成员登录、审核、Star、配额或作品权限。

1. 开启灰测并保存。进入灰测的时间单独记录；修改账号说明不会重置入组时间。
2. 填写 Creator 用户名或账号 ID 并保存。这个字段供管理员识别，来源集成不返回真实账号，因此仅填写文字不代表已核对来源身份。
3. 从该账号的投稿详情或提交回执取得作品 ID 与准确投稿版本 ID，确认这份作品属于该成员，再执行关联核对。不能用作品名或「v3」等版本文字替代准确 ID。
4. PGC 读取已授权的作品与版本，核对两者及缓存一致后保存匿名作者关联。同一来源作者不能同时关联到两位成员。已有账号对应关系可以显式解除后更正。

来源接口只提供匿名作者。这里的人员对应关系由管理员确认，作品/版本关系由来源接口核对；不能把该操作称为来源站独立认证了 PGC 成员身份。无需收集 Creator 密码或个人 Token。

灰测开关、账号填写与来源关联是三个不同状态。来源撤销、范围变化或参考作品不再可用时，关联需要重新核对，PGC 的灰测选择和管理员填写的账号说明保留。重新同步不会自动恢复失效关联。

账号关联不等于某份 AI 报告已对应准确投稿文件，也不会批量按同名关联任务。每款游戏仍需保留原审核任务、输入摘要、准确投稿版本和独立核验记录；原 AI 报告、真人回填及广场不因账号设置而改变。

设置仅供管理员访问。设备凭据和成员会话不能读取或修改这些关系；同源写入、请求幂等、修订冲突检查和源权限变化检查由服务端执行。测试及发布证据保存于私有 `artifacts/`，生产姓名、账号 ID 和原始反馈不提交仓库。
