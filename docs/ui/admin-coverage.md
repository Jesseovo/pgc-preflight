# 管理后台 React 覆盖

管理员入口为 `/admin`。页面由现有 Cookie 会话鉴权。React 通过已有管理接口读取与提交资料，保持设备协议、数据所有权和后台执行路径。

| 栏目 | 功能与接口 |
| --- | --- |
| 总览 `overview` | `GET /api/admin/dashboard`。成员和北京时间筛选、四项指标、两张可下钻的趋势图及数值表、成员贡献、四类活动任务、异常和最新成品。下钻保留半开时间范围与首次成品语义。 |
| 作品 `works` | `GET /api/admin/projects` 及所选项目、材料、原文与历史版本接口。按成员、题材或标题、来源、时间及状态查找，支持分页、卡片和列表。作品详情展示设计、材料、任务与关联报告，成品通过共享 9:16 沙箱播放器试玩，下载为附件。选定历史版本后的预览、源码与附件均带相同版本 ID。 |
| 任务 `tasks` | `GET /api/admin/tasks`。显示平台与成员 Agent 的阶段、原任务编号、失败原因及关联作品或报告。Agent 继续指令保留原任务。明确确认后调用现有平台创作重试接口。失败的平台审核任务可重新上传原文件。 |
| 审核 `reviews` | `GET /api/admin/review-activity`、`GET /api/forge/reviews/:id`。日期、成员、记录范围、完成状态及本页检索，支持分页和所选报告的 Markdown 导出。AI 分数、未知值、真人审核阶段及管理员手动导入来源分别展示。 |
| 反馈 `feedback` | `/api/admin/creator-feedback/*`、`GET /api/admin/review-metrics`。同步状态与显式唤醒、关联分页、准确投稿对照、来源规则和作品缓存、管理员声明、原始字节摘要、JSON 导出。来源决定与管理员终审分别解读，声明和文件测量保留各自证据边界。 |
| 成员 `members` | `/api/admin/members`、`/api/admin/review-pilots`。开通账号、停启用、审核权限、Star、0–10000 次额度和密码重置。灰测单独维护，可声明 Creator 账号、核对准确投稿及解除关联，保留版本前置校验和请求幂等。 |
| 平台设置 `settings` | 模型编辑、连接测试、余额、最近调用，审核及其他用途成组保存。规则草稿导入、差异和明确发布。模板与默认值、公共词条及建议审批、案例发布与取消公开。创作机制摘要目录、管理员发布与查重复核。管理员 HTML 批量上传及手动报告导入保留各文件请求编号。 |

旧版完整详情链接与 `inspect*` 参数继续有效。桌面列表和详情双栏，详情可以切换为专注查看。窄屏以全屏详情呈现，调整宽度时保留当前试玩 iframe，切换作品、版本或关闭详情时销毁原 iframe。当前作品页可切换上一款和下一款，关联对象有返回上一层入口。

本地合成 SQLite 与 Chrome 验证了总览下钻、桌面双栏与移动端同一试玩 iframe、相邻作品、历史版附件、关闭销毁、任务明确重试、审核报告、反馈声明及文件摘要、0 次额度、灰测账号声明、只写 Key 字段、词库写入和手动报告导入。预览隔离外网，平台模型、Creator Hub 在线账号核对、真实余额与真实同步均需各自授权环境验证。

生产构建对比可用 `npx tsx scripts/verify-looseleaf-performance.ts` 重跑。脚本使用两套独立静态产物、同样的合成 SQLite 数据和默认 100 ms API 响应延迟，在 Chromium 中记录首个作品行可见、四次栏目切换、作品翻页及列表接口响应。结果保存于忽略的 `artifacts/looseleaf-ui-performance.json`。这是本地管理员路径测量，覆盖按时点完成的 JS/CSS 体积与合成界面就绪时间。
