# Looseleaf Star 创作工作台

页面用 React 与共享 Looseleaf 控件，通过既有、受身份约束的 Forge API 工作。所有创作内容仍在原有数据库和任务协议里。

| 原入口 | 现有界面和行为 |
| --- | --- |
| `/forge/` 或 `?tab=picks` | 我的项目。搜索、状态筛选、列表和卡片、每页 24 个。将项目摘要和成品清单合并，保留进行中及失败状态。 |
| `?tab=draw` | 发现选题。公共词库锁定、自定义题材、抽签、批量明确提交扩写、归档。灰测开启时显示最多三个推荐、其他候选、比较状态、复查和登记。灰测关闭时保留原版抽签与候选入选。 |
| `?tab=products` | 成品清单可按项目试玩、筛选，打开准确版本并下载。 |
| `?tab=picks&project=ID&panel=create` | 选题、简报、样板图、资产、游戏制作、备注和项目状态。保留任务实际来源、等待/失败/待采用状态以及明确重试。 |
| `?tab=project&project=ID&panel=play` | 使用沙箱隔离的 9:16 播放器，下载采用的游戏。切出后销毁播放器。 |
| `?project=ID&panel=versions&version=ID` | 版本筛选、上游版本、待采用/历史、按选中版本预览与下载。采用或恢复创建新记录；可选显示源码。 |
| `?project=ID&panel=checks` | 原制作阶段、需求/补充决定、核心改动、未验证项、证据引用及按需原图和动作日志。 |
| `?project=ID&panel=review` | 选定成品版本、下载原始 HTML、复制带 `--artifact-version` 的审核指令。报告从原任务核对锁定版本和哈希。真人审核单独显示。 |
| `?tab=games` | 作品 JSON 或 XLSX 导入、查询、编辑、删除、导出及 Agent 标签。表格姓名只在浏览器内用于标记来源。 |
| `?tab=vocab` | 公共词库维度、搜索、状态和个人学习系数。题材与媒介建议由 Agent 执行，审批后入库。 |
| `?tab=settings` | 公共规则/模板只读，原版抽签数量保存在用户的本地偏好中，执行方式按用户保存在当前会话。 |
| `?tab=agent` | 创作 Agent 的专用接入、5 分钟配对码、授权设备列表与撤销。配对码仅存在于当前页面状态。 |
| `?tab=tasks` | 最近持久任务、Agent 历史、按状态/来源/项目筛选和按编号查询。链接到相应产物或项目。 |

当前 API 列表范围保持既有上限。任务列表提供已知编号查找；历史报告列表只返回最近 100 项，精确关联按单条原任务读取。浏览器能读取成员 Agent 回填的真人审核，但专用 Creator 反馈回流仍走原审核设备和管理员接口。候选即时查重记录的编号保存在当前会话，带模型的已完成查重也可从近期任务回读。核心改动通过查看自检并明确采用指定成品版本确认。

项目摘要补充 `creative_version`、`origin` 和 `requirements`，以便页面识别原版、候选种子和已登记机制，并显示创建时的补充要求。摘要继续省略 HTML、SVG 和简报原文。

合成 SQLite API 的 Chromium 验证覆盖了桌面与窄屏候选卡、选题与机制登记、排队刷新后只保留一次扩写提交、沙箱内真实点按和切页回收、版本恢复、准确审核关联、核心改动自检、作品新增/编辑/JSON/XLSX 导入及打标、补词与创作配对。XLSX 样本核对了零分、来源和总分。另有 16 项 Star API 回归通过。模型请求在本地预览中禁用。
