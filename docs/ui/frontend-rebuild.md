# PGC Looseleaf 创作与审核工作台

## 隔离与入口

预览工作分支为 `codex/looseleaf-frontend`，独立工作区为 `PGC-looseleaf`。用户确认发布后，以最新 `origin/main` 的 `3b2a824` 为基底，在 `codex/looseleaf-release` 合入前端和必要展示接口，保留已经上线的新创作流程与模型预算。本次前端不新增数据库迁移。

```sh
npm run preview:ui
# http://127.0.0.1:8790/__preview

npm run build:ui
npm run test:ui
```

预览使用仅本机监听的临时内存 SQLite、真实权限和业务 API、合成成员/项目/报告/反馈。预览不读取生产凭据、不调用真实模型、不向 Creator Hub 发请求。停止预览后合成写入不保留。

`ui.html` 为入口，`vite.ui.config.ts` 输出 `dist-ui`。正式 `npm run build` 先构建原静态资源与 Agent，再构建新界面并通过 `scripts/assemble-frontend.ts` 组装到 `dist`；`npm run deploy` 使用 `--keep-vars` 保留生产变量。登录态仍通过 `/api/auth/me`，成员和管理员使用原登录接口。

Worker 在服务页面前完成角色检查，再从 Assets binding 读取专用 `/_workbench.html`。该路径和开发入口 `/ui.html` 不允许公网直访。旧 `/admin`、`/forge/`、审核、账号和广场链接由服务端统一跳转，保留查询参数；HTML 和受限脚本私有不缓存，管理员、创作脚本分别按命名空间鉴权。旧静态脚本和 Agent 文档继续保留。

## 功能覆盖与协议

| 现有能力 | 新入口 | 权限与接口 | 验证说明 |
| --- | --- | --- | --- |
| 登录、密码与退出 | `/login`、`/admin`、`/account` | 原 auth/admin API；管理入口不出现在成员导航 | 匿名、普通成员、Star、管理员分别检查 |
| 项目、候选与制作 | `/forge/` | Star；沿用选题、机制、版本及持久任务接口 | [创作覆盖清单](creator-coverage.md) |
| 任务、报告和设备 | `/`；Star 的独立审核 | 当前审核权限和设备协议，网页不新增成员上传 | [审核覆盖清单](review-coverage.md) |
| 总览、作品、任务、审核 | `/admin?view=...` | 管理员；保留原参数与独立详情参数 | [管理覆盖清单](admin-coverage.md) |
| 反馈闭环、灰测成员 | 后台反馈/成员栏目 | 专用反馈只读缓存、声明与准确版本关联接口 | 不改写 AI 报告、规则或广场 |
| 模型、规则、词库 | 后台平台设置 | 原管理员接口；写入来自明确操作 | 不在挂载、刷新或轮询时发起模型调用 |
| 游戏广场 | `/square` | 任一启用且已登录账号；沿用真人终审条件 | 隔离试玩、显式重开、离开销毁 |
| 历史导入与资料 | 创作历史作品/词库/规则 | Star 本人及明确公开资料 | XLSX/JSON 本地解析与授权导入 |

创作的 v2 灰测开关、机制核验状态和制作阶段使用当前接口声明，不凭前端推断可执行状态。界面按准确 artifact/version/task ID 关联；项目摘要仅补齐已有创作协议、来源和要求字段，不返回游戏源码。

## 组件约定

- [Looseleaf 来源与适配](looseleaf-source.md)。所有页面使用同一按钮、表单、状态、弹窗和字体规范。
- 浅色、白底、鼠尾草绿、像素猫。候选按网格卡片展示，长信息按需展开；普通表单取消大面积纸纹和蓝色填写文字。
- 表单只有一层外框，输入框、下拉框和工具栏按钮统一高度与状态。下拉箭头不再有独立分隔栏；手机任务筛选逐项排列，文字放大时控件随行高增高。
- 已确认问题、体验判断、待验证事项分别呈现；强制修改与可选建议分离。`0` 保留为零，`null` 保留未知，AI 与真人意见分别标识。
- API 读取按页面卸载中止；轮询隐藏时暂停、错误退避。按钮动作使用同步锁，付费任务只能由明确操作触发。
- 9:16 播放器在 React 重渲染与宽度变化时保留实例；改变版本/重开才重载，离开或关闭删除 iframe。sandbox 不含同源权限。
- 错误、空数据、无搜索结果、失去权限、离线和等待 Agent 均有明确状态。键盘、焦点返回和减少动画为组件级约定。

### 成品卡片与直接试玩

成品页固定为卡片网格，兼容旧 `layout=list` 链接；「我的项目」原有列表/卡片切换保留。点击成品封面或名称直接打开共享 9:16 隔离播放器，样板图放大和查看项目保持独立入口。打开后才读取版本资料，并固定当前已采用版本；版本读取失败显示错误与显式重试。关闭窗口卸载播放器，保留列表筛选与滚动位置；点击触发器显式获得焦点，兼容 WebKit 关闭后的焦点返回。浏览列表不预载游戏、不调用模型。针对性截图与验证保存在 `artifacts/ui-product-cards/`。

本轮 Chromium/WebKit 在 1440、390、320、768 px 及 844×390 横屏的 10 组交互通过，另覆盖 320 px 的 200% 文字、搜索保留与版本读取失败。实际验证了点击输入、重新开始、缩放不重置游戏、关闭清除 iframe、样板图独立打开及焦点返回；类型检查与新前端构建通过。详见 `artifacts/ui-product-cards/metrics.json`，仍未发布生产。

### 我的项目默认卡片

「我的项目」无布局参数时默认卡片，有样板图直接展示；点击封面或名称进入该项目的创作页，不触发生成或自动试玩。样板图放大、已有成品的试玩为独立入口。列表仅在用户显式选择 `layout=list` 时显示，返回、刷新时保留选择与搜索条件。Chromium/WebKit 在 1440、390、320 px 的六组定向交互验证覆盖默认布局、两个创作入口、样板图、列表切换、返回搜索，以及缺图项目的进入。记录在 `artifacts/ui-project-cards/metrics.json`，没有模型或 API 写入。
