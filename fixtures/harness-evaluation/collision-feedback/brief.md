# 轨道分拣

## F1 题材与目标

玩家在三车道的夜班输送轨道完成限时或限步任务。目标是捡齐三个蓝色包裹并在两次红障碍碰撞前完成。使用样板图的面板结构和配色（钢蓝 #12253d、湖蓝 #63c9e8、红橘 #ff9076），素材库包含该主题的主物件绘制函数。

## F2 单局规则

左右按钮在三车道内移动一格。对象到接收线时与玩家同车道才结算。蓝包裹加一，红障碍耗一护盾，初始护盾 2，归零失败，包裹三件成功。每对象仅结算一次，邻道擦过不扣盾。
开始、操作、胜负和重开都要有实际可达的状态。成功和失败都需明确告知结果及原因，能重新开始一局，清理计时器和上局输入。未经明确批准不变更成功门槛、操控、核心资源关系或胜负条件。

## F3 操作与反馈

主操作为左右变轨。开局明确左右变轨方式，玩家所在车道易辨认。红碰撞和蓝拾取有不同文字、轮廓变化和计数反馈。视觉信号附文字或形状，同屏可分辨。

## F4 舞台与交付

单文件 HTML，540×960 逻辑舞台，桌面等比居中，移动端触点精确映射。接收线和两侧按钮在最窄尺寸保持分离。验收视口为 320×568、390×844 和 428×926。标题与玩法先于开始显示。最终 HTML 无外部资源，内联素材库并实际调用 `GAME_ASSETS.crate`。样板图给出色板和主面板比例，文字与按钮位置按可读性调整。
