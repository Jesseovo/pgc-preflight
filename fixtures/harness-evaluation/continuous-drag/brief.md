# 极地滑索

## F1 题材与目标

玩家在玻璃冰谷的救援站完成限时或限步任务。目标是同一次按住依序经过三个救援门。使用样板图的面板结构和配色（墨蓝 #102a43、冰青 #87e8f4、珊瑚 #ff927d），素材库包含该主题的主物件绘制函数。

## F2 单局规则

按住滑索柄后随横向触点移动；三扇门位于左、右、中，随时间到达，依次穿过才成功。提前松手会断开本次轨迹并明确失败。不同触摸事件不得拼接成一次拖动。
开始、操作、胜负和重开都要有实际可达的状态。成功和失败都需明确告知结果及原因，能重新开始一局，清理计时器和上局输入。未经明确批准不变更成功门槛、操控、核心资源关系或胜负条件。

## F3 操作与反馈

主操作为拖动滑索柄。把手有可见的可拖动提示；任一尺寸下横向触点与把手同步。门通过、撞门、提前松手显示独立反馈和当前门数。视觉信号附文字或形状，同屏可分辨。

## F4 舞台与交付

单文件 HTML，540×960 逻辑舞台，桌面等比居中，移动端触点精确映射。中途手指覆盖把手时仍能看见下一道门和门数。验收视口为 320×568、390×844 和 428×926。标题与玩法先于开始显示。最终 HTML 无外部资源，内联素材库并实际调用 `GAME_ASSETS.sled`。样板图给出色板和主面板比例，文字与按钮位置按可读性调整。
