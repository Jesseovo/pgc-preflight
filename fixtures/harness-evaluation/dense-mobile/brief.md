# 微缩温室

## F1 题材与目标

玩家在小屏多区水培控制台完成限时或限步任务。目标是在六次操作内将四区全部校正。使用样板图的面板结构和配色（松绿 #133a36、嫩绿 #96e0aa、杏黄 #ffc57d），素材库包含该主题的主物件绘制函数。

## F2 单局规则

四区初值为 1、3、0、4，目标区间 1–2，水罐初值 3，最大 5。各区提供加水和排水键，各成功操作移一格，加水从罐扣 1，排水向罐返 1。合法操作累计六次后仍有异常即失败，四区同时合格即成功。越界或水罐不足的动作不计次。
开始、操作、胜负和重开都要有实际可达的状态。成功和失败都需明确告知结果及原因，能重新开始一局，清理计时器和上局输入。未经明确批准不变更成功门槛、操控、核心资源关系或胜负条件。

## F3 操作与反馈

主操作为切换分区阀门。区名和按钮标签可区分，并清楚显示禁用和余量。相邻区域变化不会被误认为当前区，目标带及水罐余量有文字提示。视觉信号附文字或形状，同屏可分辨。

## F4 舞台与交付

单文件 HTML，540×960 逻辑舞台，桌面等比居中，移动端触点精确映射。320×568 视口无横向溢出，四行控制和底部说明可读可达。验收视口为 320×568、390×844 和 428×926。标题与玩法先于开始显示。最终 HTML 无外部资源，内联素材库并实际调用 `GAME_ASSETS.sprout`。样板图给出色板和主面板比例，文字与按钮位置按可读性调整。
