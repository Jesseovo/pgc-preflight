# 雾塔修路

## F1 题材与目标

玩家在逐层通电的雾中天桥完成限时或限步任务。目标是过三层桥后安全到达顶层。使用样板图的面板结构和配色（岩紫 #26223f、浅蓝 #8cceff、夕橙 #ffad77），素材库包含该主题的主物件绘制函数。

## F2 单局规则

每层亮出一个正确踏板，关闭提示后只允许选择一次。第一层两块并亮 1500 ms，第二层三块并亮 1000 ms，第三层四块并亮 700 ms。误选立即失败，三层正确即成功。两种终局均提供重开，重开回第一层并清除旧计时器、旧分数和输入。
开始、操作、胜负和重开都要有实际可达的状态。成功和失败都需明确告知结果及原因，能重新开始一局，清理计时器和上局输入。未经明确批准不变更成功门槛、操控、核心资源关系或胜负条件。

## F3 操作与反馈

主操作为点亮安全踏板。显示层数和清晰的等待、选择状态；不可提前蒙点。过层反馈、失败原因和重开按钮分明，连点重开不会多开计时。视觉信号附文字或形状，同屏可分辨。

## F4 舞台与交付

单文件 HTML，540×960 逻辑舞台，桌面等比居中，移动端触点精确映射。四块踏板和重开区在最窄尺寸有可辨认分隔。验收视口为 320×568、390×844 和 428×926。标题与玩法先于开始显示。最终 HTML 无外部资源，内联素材库并实际调用 `GAME_ASSETS.bridge`。样板图给出色板和主面板比例，文字与按钮位置按可读性调整。
